# character/

`RobotExpressive.glb` — created by Tomás Laulhé, released CC0 1.0 (public
domain). Facial expression morph targets added and re-exported by Don McCurdy.
Vendored from
[mrdoob/three.js](https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/RobotExpressive),
which ships it under the same CC0 terms.

One character, on purpose — see `specs/F03_MOCAP.md`'s scope cuts. Swapping or
adding a second rig means adding its own bone-name mapping in
`js/mocap-retarget.js`, not just dropping a file in here.
