Browser-Local Semantic Search

Built the search on this site to run entirely in the visitor's browser, with no inference server: (1) all-MiniLM-L6-v2 quantised to 8-bit, executed by ONNX Runtime on WebAssembly; (2) Transformers.js embedding the question client-side, with the model, runtime and weights all served from origin so nothing is fetched from a model hub at runtime; (3) Exhaustive cosine search rather than an approximate index, which at this corpus size costs more than it saves.

No API key, no inference cost, no data leaves the tab

Answers in ~25ms after a one-time load
